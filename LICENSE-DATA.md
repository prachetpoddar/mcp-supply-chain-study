## What the data is, and what it is not

The datasets consist of factual metadata retrieved from the public npm registry
API, the public PyPI JSON API, the public Docker Hub repository API, and the
public Model Context Protocol registry, together with statistics derived from
that metadata.

No third-party package source code is redistributed. Where a package's declared
licence identifier or the presence of a licence file is recorded, that record is
a statement about the package, not a copy of it. Package names, version strings,
download counts and dependency relationships are facts about publicly published
software.
